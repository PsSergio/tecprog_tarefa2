# Biblioteca Modular de Cálculo 1 em C

Projeto desenvolvido para o Trabalho Prático 2 da disciplina de Técnicas de Programação. 
Consiste em uma biblioteca em C que realiza mapeamento de equações matemáticas, diferenciação com manipulações simbólicas, cálculo de limites analíticos com Regra de L'Hôpital.

---

## 1. Pré-requisitos
* Sistema Operacional: Linux
* Compilador: `gcc` 
* Ferramenta de automação: `GNU Make`
* Controle de versão: `git`

## Makefile
A configuração no Makefile permite os seguintes comandos:
* make all
* make run
* make test
* make install
